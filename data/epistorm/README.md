# Epistorm-Mix contact matrices

Setting-specific age contact matrices (M-matrices, 5-year age brackets with a
75+ group) copied without modification from the Epistorm-Mix repository:

- Source: <https://github.com/epistorm/Epistorm-Mix/tree/main/matrices/M_matrix>
  (commit `2bcfe4311fd8937c743adc3f1f087891cec33c37`).
- Files: `Household-M-by5_75-matrix.csv`, `School-M-by5_75-matrix.csv`,
  `Work-M-by5_75-matrix.csv`, `Other-M-by5_75-matrix.csv`.
- Entry `[i, j]` is the weighted mean number of daily contacts that a
  respondent in age group `i` reports with people in age group `j`. The four
  settings add up to the `Total` matrix in the source repository.
- These are aggregate, published matrices. No individual-level survey data is
  included here.
